# MY FIRST STREAMLIT APP 

This is simple project made in college as a practice exercise. It does a search about market data of different companies as the user specifies

## What it does:
- Search historical data from the given company through the yahoo finance api (yfinance)
- Show it as a line chart using matplotlib
